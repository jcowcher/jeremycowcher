Claude Cowork needs to show the dust

The dust and dirt in vacuum cleaners used to be hidden until James Dyson decided to use a clear bin.

"Using a clear bin in our vacuum was another 'clear' example of going our own way. Trusting our own instincts, we decided to ignore the research and retailers. Pete and I had been developing the vacuum cleaner and we loved seeing the dust and dirt. We didn’t want to hide away all the hard work the machine had done."

— James Dyson (Invention: A Life)

You've probably seen two things on X this week: a growing dissatisfaction with Opus 5's written text and the emergence of Grok Bot. I believe these two things are linked. In written text Opus 5 has felt like a regression from Opus 4.8, even though I've found it better at doing the coding.

If there was an easy fix for these written text issues, Anthropic would have pushed it out already. Claude was working better than almost any product ever and so this "wobble" has given me an opening to advocate for a change I've wanted to see in Cowork for a while: take a lesson from James Dyson and show the "dust". In this case, that means showing Claude's work in Cowork.

Right now, when Cowork runs something for you, including writing code, you generally just see one line at a time, something like "Running a command on your computer" or "Reading files on your computer". When it finishes, you might get a one-line summary like "Used 2 tools" or "Used 3 tools, ran a command".

Run the same prompt in Claude Code (I run Claude Code inside VS Code) and you'll get a one-line summary like "Ran 2 shell commands" and then you'll see the code changes. Claude Code shows the "dust" of code changes; Cowork does not.

I suspect this decision was made because Cowork is designed for non-technical users and Anthropic's concern was that the code changes were "noise". I disagree with this.

When I first started using Cowork, I didn't like that I couldn't see its work, especially if something didn't turn out how I wanted it to. If anything I've gotten stronger in this stance over time, and have hardened my CLAUDE.md rule that anything touching code happens in Claude Code. Where Cowork is really helpful is writing the prompts that I can feed to Claude Code to update the code.

When the end result is great, opacity doesn't matter. With this recent "wobble" for Claude, showing the "dust" does two jobs: it softens the wait, and by seeing the work being done, it can make you feel better about the end product. Anthropic will improve the written text wobble and be fine; in the meantime it can stop hiding all the great work its "machine" has done.
